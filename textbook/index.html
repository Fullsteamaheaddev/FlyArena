Description

A complete nervous system is now a file: 165,122 neurons, 104 million synapses. This book asks what that file computes. It follows a pipeline that reads the wiring, proposes the computations, builds the families of models the wiring permits, and ranks the experiments that decide between them, worked end to end on three circuits of the male Drosophila CNS. Then it runs the whole brain in a body and reports which behaviours the wiring supports and which it does not.

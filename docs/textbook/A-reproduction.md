# Appendix: Reproduction

Every number in this book is generated by a committed script and a committed artifact.
The pipeline is deterministic (seeded RNG throughout); rerunning any stage reproduces
the cited table.

## Pipeline order

```bash
# IR and generic structure (Ch. 2-3)
python3 scripts/connectome_ir.py      # fly + worm -> canonical IR
python3 scripts/algo_ir.py            # IR -> generic structure report
python3 scripts/check_structures.py   # fly-through-IR reproduces algo_structures.json

# Operator detection (Ch. 4)
python3 scripts/operators.py          # structure report -> public/data/operators.json

# Ensembles (Ch. 5-6, 9-10)
python3 scripts/ensemble_spec.py      # -> public/data/ensemble_specs.json
node scripts/run_ensemble.mjs ring_attractor
node scripts/run_ensemble.mjs phasor_vector_shift
node scripts/run_ensemble.mjs sparse_associative_memory
# (the original hand-written labs: hypothesis_lab.mjs, phasor_lab.mjs)

# Field model and perturbations (Ch. 7-8)
python3 scripts/ring_pde.py           # self-check: bump, integration, landmark remap
python3 scripts/perturb_pde.py        # -> public/data/perturb_pde.json

# Benchmark (Ch. 11)
python3 scripts/bench_heading.py
```

## Notation conventions

- Ensemble "members" are parameter points; "classes" are behavior labels assigned by
  the probe; "mechanisms" are the perturbation-outcome subclasses.
- Separation scores are ensemble-splitting measures in [0,1]; a score near 0.5 at
  small ensemble size is near-maximal.
- All bump widths are FWHM in degrees; all benchmark scores are radians RMS.
- "Wired" refers to quantities read from synapse counts; "realised" to quantities
  measured in simulation.

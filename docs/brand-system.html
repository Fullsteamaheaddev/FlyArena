Flies Armageddon

1. Brand essence

Flies Armageddon is a spectator race built on a real fruit-fly connectome sim: competitive, funny, slightly chaotic, but grounded in science. Tone is arcade energy (Worms-style mayhem) with warm wood-and-cream game UI — not sterile lab chrome.

  • Promise: watch tiny brains compete; cheer, bet, survive the chaos.
  • Personality: loud, playful, lucky, slightly apocalyptic (stone wordmark, explosions in key art).
  • Audience: crypto spectators, bio-curious gamers, chaos enjoyers.

Taglines (approved)

  • Welcome to Flies Armageddon (enter gate)

5a. Container reference (visual)

LobbyContainer.png Full garden frame: grass/leaf corners, wood edges. Slice 17% 21% 24% 21%, border 70px. Hang Flieslogo.png above top edge (.lobby-brand, ~78px breathe padding).

Button.webp Orange wood CTA slab (1663×473). White Luckiest Guy label + warm shadow 0 2px 0 #7a3a00. Scale hover 1.08 — do not swap to flat CSS buttons in race mode.

When to use which frame

  • Headless — persistent HUD, smaller footprints, score/clock/brain traces; pairs with fly-tinted chips inside.
  • Lobby — modal moments: betting lobby, race results, wallet choice. Portrait only. Wordmark hangs above the top edge, not inside the cream.
  • Landing — enter gate and landscape social comps (3:2 / 16:9). One plaque, native ratio, wordmark at top: -8% centered (~36% of plaque width).

5c. Hard layout rules

These failed in the first rebrand infographic: a portrait lobby nine-sliced onto a 1500×1000 canvas, the stacked wordmark used as a giant left column, and copy sitting on the grass rail / outside the board.

Do
  • Pick the frame whose native ratio matches the canvas (landing ≈ 3:2; lobby ≈ portrait).
  • Keep all type, logos, and swatches on the cream inner board — never on wood, leaves, grass, or rocks.
  • Size logos with width + height: auto + object-fit: contain. Preserve 954×725 for the wordmark.
  • Landing enter gate copy uses inset 11% L/R, 34% top, 14% bottom.
  • Landing infographics use a wider cream: ~12% L/R, ~20% top, ~12% bottom, content optically centered — not bunched under the wordmark with empty parchment below.
  • Letterbox a frame on sky/cream if the canvas is the wrong shape. Empty sky is correct; stretched wood is not.
Don’t
  • Nine-slice LobbyContainer across a wide 3:2 or 16:9 rectangle.
  • Put footers, handles, or headlines outside / overlapping the frame.
  • Put a second logo, hero explosion, or URL footer inside a plaque that already has the wordmark on top.
  • Use white Luckiest Guy + stroke for titles sitting on cream (that style is for in-scene shouts).
  • Use background-size: cover or fill on chrome PNGs.
  • Set only width or only height on the wordmark in a way that changes aspect.

Nine-slice is not a free stretch. border-image tiles the center so a HUD can grow a few dozen pixels. It does not license changing a portrait garden board into a landscape poster.

5b. Containers in marketing

Social art should feel like the game: sky backdrop, cream boards, wood edges — at native container ratios.

  • 3:2 / 16:9 comps: LandingContainer.png at 1198×766, contain, centered on #c5dce8. Do not use lobby.
  • Portrait stories / posters: LobbyContainer.png near 1889×2115. Wordmark hangs above.
  • Composites: key art or screenshots sit inside the cream; never crop off corner leaves.
  • Screenshots: race HUD with headless panels at ~1.59:1 — that is the live brand.
  • Do not replace wood with generic rounded rectangles, Material cards, or lab dark glass (#panel) in race marketing.
  • Host gate is an exception (dark grey outline UI) — not for public marketing hero shots.

Chips, nametags & motion (in-frame UI)

Nametag pills: dark translucent fill, 2px fly-color border, Luckiest Guy name. Hover stat card = vitals chip (cream + --fly tint, 12px radius, shadow 0 8px 22px rgba(42,24,16,.28)). Panel motion: fold ease cubic-bezier(0.34, 1.2, 0.64, 1), HUD slide 0.45s; lobby card enter scale raceCardEnter + idle breathe on enter gate.

Layout wireframe

3:2 · 1500×1000

Dashed box = 5% safe margin (75 px at 1500 width). Keep logos and type inside.

Layer stack (top → bottom)

Grid

  • Safe cream ≈ 12% left/right, 20% top, 12% bottom of the plaque (looser than enter-gate fill).
  • Title spans full cream; then grid-template-columns: 1fr 1fr 1fr with equal gap.
  • Max ~3 items per column. Labels wrap to two lines only if needed; no paragraphs.
  • Swatch row: 5 chips, no wrap, centered, ~8–12px above the inner bottom of the cream.

7. Voice & copy

  • Short sentences. Present tense. Exclamation sparingly — chaos toasts can be louder than UI labels.
  • Death causes are full phrases (“killed by lightning”), never single nouns.
  • Science is real but not preachy: neuron counts and “brain” language are fair game; don’t promise real-money outcomes beyond on-chain pool rules.
  • Brand name is always Flies Armageddon (two words, title case). Not “Sugar Run” (retired).

8. Do / don’t

Do
  • Use Flieslogo on cream or sky backgrounds.
  • Use FliesImageLogo for social/Open Graph.
  • Tint UI with racer fly colors via --fly.
  • Use the four wood container PNGs (§5) for race UI and on-brand comps.
  • Keep wood frames; don’t replace with flat Material cards in race mode.
Don’t
  • Reuse retired card.webp Sugar Run neon art.
  • Stretch or recolor the stone wordmark gradients.
  • Nine-slice a portrait lobby frame onto a landscape social canvas.
  • Let type, handles, or footers sit on wood rails, grass, or outside the plaque.
  • Drop hero art or a second wordmark inside a plaque infographic (the hanging logo is enough).
  • Set plaque titles in white Luckiest Guy; use wood-ink extra-bold on cream.
  • Place wordmark on busy mid-tone photos without a cream plate behind it.
  • Mix lab dark theme into race lobby without intentional contrast (e.g. host gate exception).
